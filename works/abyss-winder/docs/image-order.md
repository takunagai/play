## 自力描画で成立する理由

主役は入力角度に応じて円周へ巻かれる索と、完遂時にだけ閉じる水圧輪である。固定画像にすると操作由来の曲率・連続性・0.14秒停止が読めなくなる。Canvas の円弧・ベジェ曲線・小さな目盛りで直接描く。

| 要素 | 描画方法 | 制限 |
|---|---|---|
| 海底 | `#08152B` の不透明な面と少量の暗い粒子 | 茶色の面・全面グロー・矩形の粒子境界を作らない |
| 丸窓・金属 | `#56616B` の細い複数円弧と小さな留め具 | 画面中央の主役を埋めない |
| 錆びた索 | `#8A4F38` の二重の曲線と細い撚り目 | 錆は索のみ、指へ直線吸着させない |
| 目盛り・閉鎖輪 | 白い短線、`#43B9D8` の細い輪と局所的にじみ | 発光は最終目盛りと閉じる輪だけ |
| 魚影・泡・ガラス水紋 | 少数の曲線・円弧、淡い反射 | 外部画像なし、停止時計を共有 |

## サムネイルの扱い

構想段階の `public/thumbnail.webp` は自作の静的構想図であり、生成AI画像でも実装のスクリーンショットでもない。`pnpm check` の必須サムネイル契約を満たす初期アセットとしてのみ使用する。音響・仕上げ担当が実作品の `pnpm verify` スクリーンショットから1200×630のwebpへ置き換える。構想図を完成画面の証拠に使わない。

後から生成素材が必要になっても本発注の範囲には含まれない。発注変更と承認を先に取り、作品全体で10枚以下、採用画像の `file`・プロンプト全文・`model` の記録を守る。透過が必要な場合は黒背景で生成し、実装担当が `prepare-image.mjs` でwebp化・黒抜きを行う。
