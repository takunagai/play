# 光のドミノ ─ 画像発注書

## 発注枚数

生成画像なし（0 枚）。

## 判断理由

主役は、ユーザーがなぞった曲線に沿ってその場で生成される板、連鎖中の倒れ方、床へ残る光の筋である。固定画像を置くと、入力から生まれた形より背景装飾が強くなり、「自分が描いた模様が 1 枚の絵になる」という終わり方を弱める。板、墨色の床、金の芯、周辺光、衝撃波はすべて 2D canvas で軽量かつ解像度非依存に描けるため、画像生成は行わない。

`work.json` の `generatedImages` は `[]` のままとする。したがって `scripts/prepare-image.mjs --black-to-alpha` の対象もない。将来、発光素材を追加する仕様変更が入った場合は、黒背景で生成して `--black-to-alpha` で透過化するが、本企画の Tier 1 には含めない。
