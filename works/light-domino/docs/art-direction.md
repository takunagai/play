# アートディレクション案 ─ 光のドミノ（再設計）

独立案。既存実装（`src/main.ts` / `src/style.css` / `index.html`）、`.verify/`、`dist/` は参照していない。根拠は `docs/taste-guide.md` と再設計テーマのみ。

- テーマ: **「暗い展示室の床の上で、自分の描線が光の楽器／星図に育つ」**
- 解決する欠陥（ユーザー評価「単調すぎるしビジュアルもショボい」）:
  - 単調 → 状態ごとに「主役」を 1 つ定義し、連鎖には床の照り・色温度の物語を与える（第 3 章）
  - ショボい → 板を「物体」として描く（厚み・影・エッジ反射）。光はベタや太いリングではなく細い蕊と低 alpha の単一グロー（第 2〜3 章）
  - 第 2 強化ラウンドで追加する欠陥（「表現が弱い・単調・最長が短い・板が小さい」）への答えは、素材の追加ではなく**時間とスケール**である（第 2・5・7 章）。床と星図は常に呼吸し、板は物体として大きくなり、連鎖と終演は長さに比例して豪華になる
- 色は 4 系統に絞る: 墨 / 冷たい照り / 温かい白 / 金。光の演出はこの 4 色の alpha と合成だけで行い、状態ごとに新しい色を作らない
- **背景画像（ビットマップ）は不採用**（lead 裁定・第 2 強化ラウンド）。「動くオブジェクトや背景画で賑やかす」代わりに、コード描画の「生きた展示室」で深さと時間を与える。理由:
  - (a) 静的なビットマップは連鎖に応答できない。光源に反応する床・連鎖と同期した環境の変化はリアルタイム合成が前提で、応答しない背景は死んだ描画として世界観を壊す
  - (b) 写実的な質感は第 0 章の「色 4 系統 + alpha」規律・taste-guide の安い見た目禁止（合否 9）と衝突するリスクが高い
  - (c) 60fps・モバイル GPU 予算を画像デコードと大型合成に割れない
  - (d) 「静謐な展示室」という世界観の純粋さ。賑やかさは動きと音で与え、絵は静かに保つ
  - 代わりの遠景はコード描画に限定する: 壁と床の境界線 1 本 + 柱の気配 3〜4 本 + 床の照りのドリフト + 連鎖に同期した照りの移動（第 1 章・第 7 章）
  - 禁則の維持: ドリフト・星図の呼吸・収縮も「状態によって影の方向を変える」「画面全体のフラッシュ」「新しい色」には当たらない（第 6 章）

## 0. カラートークン（全章で参照）

| トークン | 値 | 用途 |
|---|---|---|
| `ink` | `#111318` | 床・周辺減光・床影の素（決定済み） |
| `coolGlow` | `#1A1F29` | 床の冷たい照り。「冷たい低コントラストの面」の許可内の具体化 |
| `warmGlow` | `#2A2620` | 連鎖終盤の照り。`coolGlow` の温度補間先であり、独立して描かない |
| `warmWhite` | `#FFF4E0` | 立っている板・エッジ反射・文字（決定済み） |
| `gold` | `#FFC857` | 倒れた板・蕊・節点・パルス・開花（決定済み） |

合成の規律（破ったら濁り・白飛びになるので本書中で最優先）:

- 金の蕊は **alpha 1.0 で 1 回描く**。低 alpha の金を多層重ねて金を作らない
- 加算合成（グロー）に使うのは `gold` のみ。同一地点のグロー積算 alpha は **0.12 以下**、重ねる層は **最大 2 層**
- 色の補間は「照り 1 層の内部」だけで行う（`coolGlow` ↔ `warmGlow`）。板・蕊は途中混合を作らず **2 値切替**（茶色を生まないため）
- どの状態でも画面の最大輝度は `warmWhite` に達しない（白飛び禁止）

## 1. 世界観と床の作り（深さの源泉）

比喩: 美術館の暗い展示室。磨かれた墨色の石床の上に作品だけが置かれ、壁は暗闇に沈む。光源は画面上手前上部のスポットライト 1 灯で、**全状態を通じて不変**（影の方向を状態で変えない）。

床は黒一色にしない。「深さ」は次の 4 層で作る。いずれも静的式で、画質段（quality）が変わっても同じ式で描く（taste-guide 第 2 節 prism-pop Phase 5 の教訓: 段が変わっても見た目をそろえる）。

描画順（下から）:

1. **L0 床ベタ**: `ink` で全画面塗り
2. **L1 冷たい照り**: キャンバス中心（演奏後は直近の道の重心へスライド、第 3 章）を中心とする放射。`coolGlow`、半径 = `min(w, h) × 0.55`、中心 alpha 0.5 → 縁 0 の 1 層。縦長画面では縦:横 ≈ 4:3 の楕円に伸ばす
3. **L2 ガイド線**: 間隔 48px（375px 幅では 32px）の格子、`warmWhite` alpha 0.03、線幅 1px。**動かさない**（静けさの担保）。等高線（同心円・間隔 64px・alpha 0.025）でもよいが、必ずどちらか 1 本に絞る
4. **L3 周辺減光**: 四辺へ向かって `ink` alpha 0 → 0.55 の上塗り。長辺方向は短辺より緩く効かせる（楕円の減光）

遠景の展示構造（第 2 強化ラウンドで追加。背景画像ではなくコード描画）: 壁と床の境界線を画面上部 約 22% の高さに `warmWhite` alpha 0.025・線幅 1px で 1 本引く。線の上（壁側）に柱の気配を 3〜4 本、`warmWhite` alpha 0.015 以下の縦の帯として等間隔に置く。いずれも L2 ガイド線と同じ**静的レイヤーへ焼き付け**、動かさない。**境界線より下（床側）には何も置かない**（床は作品の舞台。遠景が床に降りてこないことで「広い床」が読める）。

床影の原則: 影は `ink` alpha 0.5 の 1 回描きで、**照りの内側でだけ視認される**（照りの外では床に溶ける）。新しい色を作らず展示室の物理として正しい。方向はスポットライトの逆、offset (3, 4)px。

## 2. 板の物語性（立ち・倒れ中・倒れた）

板 = ドミノ 1 枚。線に沿って間隔 16px（375px では 12px）で配置。真上俯瞰に擬似 3D を足し、厚みで物体温を出す。**第 2 強化ラウンドで板を物体として大きくする**: ユーザー評価「各ドミノが小さすぎる」を受け、1280px では板幅 10 → 13px、奥行 6 → 7px、倒れ後の長さ 22 → 32px。375px でも板幅 8 → 9px、奥行 5 → 6px、倒れ後の長さ 18 → 24px へ広げ、両幅で「指で置いた物体」の存在感を上げる（スケール表は第 5 章）。

### 立ち（idle）

- 上面: `warmWhite` alpha 1.0 の矩形。幅（線に直交）13px、奥行 7px。周囲 1px を `ink` alpha 0.25 で縁取り（床から浮く境界）
- 手前側面: 上面の手前側に幅 2px の帯。`warmWhite` を **alpha 0.35 で 1 回** 描く（多層にしない）。上面と帯の明度差が「厚み」を読ませる
- 床影: 第 1 章の原則どおり `ink` alpha 0.5、板 + 2px、offset (3, 4)px
- エッジ反射: 上面の長辺両端に線幅 1px の `warmWhite` alpha 0.4。金属の縁の光。**リング状の縁取りは作らない**（太い原色リング禁止）

### tracing（なぞり中）─ 主役: 仮の板列が手の延長に見える

- 仮板列: 立板と同じ形で `warmWhite` alpha 0.55、影なし・縁取りなし。指位置（最新点）から直近 3 枚は alpha 0.55 → 0.9 で濃くなり、描いた端が「生きて」いる
- 追従: 板列は指の最新点へ即時に追従する（手の延長感。実測では専用の遅延定数は置かず即時追従。architecture §3.2 と同じ）
- 残像: 通過直後の点に半径 6px・`warmWhite` alpha 0.15 の丸を 120ms だけ置きフェードアウト。積算しない
- 画面下部 48px は誤操作防止の無視領域（枠は描かない）

### aligned（整列）─ 主役: 押せる端

- 全板が「立ち」の完全表現（影 + 縁取り + エッジ反射付き）に昇格する
- 押せる端 = 始点側 3 枚（375px では 2 枚）を強調: 幅 +2px、alpha 0.85 ↔ 1.0 の緩い明滅 1.2Hz。位相は端から順に 80ms ずつ遅らせ、押したくなる波にする
- 案内は 1 語のみ画面下部 12%、`warmWhite` alpha 0.6

### 倒れ中（falling）

- 時間: 1 枚 140ms。角度 θ は 0 → 90° を easeInQuad（跳ね返り・弾みは作らない。静謐さ優先）
- 動き: 上面の奥行 7px → 線方向 32px へ伸び、手前側面の帯は消える
- 色の切替: θ 60° で上面を `warmWhite` → `gold` に **2 値切替**（混色して茶色を作らない）
- 床影: 倒れ方向へ offset を (3, 4) → (0, 8) に lerp。着地で alpha 0.5 → 0.15（板自身が光源になり影が消える）

### 倒れた（fallen、音が鳴った板）

- 上面: `gold` alpha 1.0、1 回描き
- 蕊: 板中心線に `gold` alpha 1.0・線幅 1.5px の線。**不透明で 1 回**（第 0 章の規律）
- エッジ反射: 上面長辺両端に `warmWhite` alpha 0.4・1px（立ちと同式。質感が状態で別物にならない）
- グロー: `gold` alpha 0.08、板 + 8px の矩形を加算 1 層。着地から 300ms で alpha 0.03 まで減衰し、**0.03 を維持**（倒れた板は消灯しない「灯り続ける楽器」。操作結果が絵に残る＝ taste-guide 合否 5）

## 3. 連鎖と終演の光

### chain ─ 主役: 板を追う発光パルスと、床の照りの移動

- 順伝播: 1 枚あたり 140ms（倒れ時間と同期）。視覚側は着地 0ms で反応。連鎖間隔を拍に乗せるのは音側の設計（heartburst Phase 16 の教訓を音に委ね、視覚は着地に追従するだけ）
- パルス: 着地した板の位置に `gold` alpha 0.10 の円、半径 18px（375px では 14px）→ 140ms で 34px へ拡大しながら alpha → 0。**同時存在数は最大 2**（連鎖が速くても画面を濁さない）
- 局所灯（床の照りの移動）: 第 1 章 L1 の照りの中心を、**直近 4 枚の倒れた板の重心**へ 0.5s かけて線形スライド。床が連鎖を追いかけて照らされる
- 明度・色温度の物語: 連鎖進行度 t（0 → 1）で
  - 照りの alpha 0.5 → 0.8
  - 照りの色 `coolGlow` → `warmGlow` へ t で線形補間（照り 1 層の内部補間。第 0 章の規律内）
  - 未倒れの立板は alpha 0.9 → 1.0 へわずかに上がる
- 物体温: 板の厚み・影・エッジの式は連鎖中も変えない。光の担い手は倒れた板だけ
- 休止: 板列が 2s 以上途切れたらパルスを止め、床を静寂に戻す（aligned の端の明滅で再誘い）

### finale ─ 主役: 道に沿った柔らかい光の開花

- トリガ: 最終板の着地から 200ms 後
- **長さに比例した終演（第 2 強化ラウンド）**: 終演の豪華さを連鎖進行度 t（0 → 1。その演奏の連鎖進行率）へ比例させる。短い演奏は t ≈ 0 で従来どおり、長い演奏ほど開花が長く・衝撃波が大きくなる
- 開花: 道の全点に沿い、始点 → 終点へ 800 + 800t ms（0.8〜1.6 秒）で走る明るさの波。金の蕊が一時的に線幅 1.5 → 3px、伴うグローは `gold` alpha 0.10・幅 24px（加算 1 層）。**全画面フラッシュは作らない**（最大輝度は `warmWhite` 未満）
- 衝撃波: 終点から 1 回だけ。半径 0 → `min(w, h) × (0.4 + 0.15t)`（最大 0.55）を 600ms、線幅 1px・`gold` alpha 0.12 → 0 の細い円弧。太いリングは禁止なので 1px・低 alpha・1 回限り
- 余韻: 800ms かけて全板のグローが alpha 0.03 に落ち着き、commit 待ちの静寂を 0.8s 置く（溜め。heartburst Phase 9 の「解放前の間」の視覚版）

## 4. 結果の絵（蓄積・節点・残光・星図）

星図の比喩を採用する: 板 1 枚 = 星 1 個、演奏 1 回 = 星座 1 個。

**星図の呼吸（第 2 強化ラウンドで追加）**: 確定済みの節点は、「intro と確定後の静置（settled = 確定アニメの終わった後の待機。実装状態名は architecture §3 の英字値に従う）」の間、`gold` alpha 0.35 → 0.5 の範囲を周期 4〜7 秒のサインで脈動する（眠る光の断片と同じ周期帯。**節点ごとに位相をずらす**ので、星図全体がゆっくり波打つように息をする）。chain の間と、確定までの finale の間は凍結し、脈動の位相を保持したまま静止する（連鎖の動きと星図の動きが競合しないため）。脈動は節点の alpha のみで行い、半径・位置・蕊は動かさない。

- 確定は対話を待たない: 余韻の静寂の後、終演和音の開始から 1200ms 後（`settleAtMs`）に自動で確定する（操作は確定の条件にならない。architecture §3.5 と同じ）
- 確定アニメ: 自動確定と同時に、**終点 → 始点へ 500ms で逆走する金の描線**のグロー走査が掛かる（「重ねて描いた道」の演出。星を結ぶ線を引く動作。旧「commit の誘いの押下」は再設計で置かれ、自動確定に同期した演出として行う）
- 確定道の構成（第 1 章の描画順でいう「L2 ガイド線の直上・L3 周辺減光の直下」に置く永続レイヤー。以後減衰しない）:
  - 蕊: `gold` alpha 1.0・1.5px、1 回描き
  - 節点: 板 1 枚につき `gold` alpha 1.0・半径 2px の円 + alpha 0.3・半径 5px の外殻（加算ではなく通常合成の 2 層）
  - 残光: 直近 1 回の演奏の板は確定後も 10s かけてグロー alpha 0.03 → 0 に減衰し、「昨日の星」になる。蕊と節点だけが残る
- **交叉の扱い**: 道が自分自身と交差する点では節点を置かず、蕊の alpha を積算しない（交叉点が濁らない。積算レイヤーは加算でなく通常合成で上書き描きする仕様とする）
- **並走の扱い**: 既存の蕊と 6px 未満で並走する区間は、新しい道のグローを 0 にして蕊だけで描く（近接部が格子状に濁らない）
- 蓄積の上限: 節点は画面あたり 300 個まで。超えたら古い演奏の残光から消し、蕊は alpha 1.0 → 0.5 に減衰して**消さない**（星図＝記憶は消えない、という世界観）
- intro への接続: 次の演奏の intro では星図が眠る星として床に残り、新しい描線はその星を結ぶように引ける（星図は記憶の地図であり、次の演奏の素材）

## 5. 375px モバイル独立設計（1280 の縮小版にしない）

スケール基準を「幅の縮小」ではなく「板列の読みやすさ」に置く。数値はすべて独立に決める。

| 項目 | 1280px | 375px | 理由 |
|---|---|---|---|
| 板間隔 | 16px | 12px | 細身でも列のリズムを保つ（据え置き。板を大きくしても隙間の墨 3px は両幅で読める） |
| 板幅 | 13px | 9px | 第 2 強化ラウンドで 10/8 から拡大。物体としての存在感（旧下限 8px の隙間 3px は隔 16/12px と整合） |
| 板の奥行（立） | 7px | 6px | 第 2 強化ラウンドで 6/5 から拡大。厚みの錯視が消えない |
| 倒れ後の板の長さ | 32px | 24px | 第 2 強化ラウンドで 22/18 から拡大。パルス・開花の最小単位としての存在感 |
| 描線判定半径 | 12px | 22px | 指の太さ前提 |
| パルス半径 | 18 → 34px | 14 → 28px | 画面占有率を両幅で揃える |
| 節点半径 | 2px | 2px | **縮小しない**（星図が読めなくなる） |

- 縦長補正: 幅 < 高さのとき、板の奥行と倒れ後の長さを 1.2 倍（prism-pop `CREATURE_PORTRAIT_SCALE` の教訓の踏襲。ただし板は列の一部なので 2 倍にしない ─ 過剰拡大で列が崩れる）
- 各状態の主役と画面占有率（375 × 667 想定）:
  - **intro**: 主役 = 床の照りと寝ている光の断片。画面上半分 ≈ 55%。文字は脇役として下 22% に帯を置き、タイトル 22px 1 行（alpha 0.85）+ 案内 13px（alpha 0.55）
  - **tracing**: 主役 = 指先の仮板列。道は画面の ≈ 70% を横断してよい。下部 48px は無視領域
  - **aligned**: 主役 = 板列全体。中央 ≈ 50%。押せる端の明滅は 2 枚まで
  - **chain**: 主役 = パルスの走り。同時 2 枚制限は据え置き
  - **finale**: 主役 = 道の開花。衝撃波は縦長の `min(w, h)` で縦に伸びる
  - **星図**: 節点 2px 据え置き。近接する道の蕊は alpha 0.8 に下げ混線を防ぐ
- 横スクロール禁止の担保: 画面端 24px は描画不可領域として扱い、はみ出す板を作らない（枠は描かない。taste-guide 合否 8）
- intro の「寝ている光の断片」: 12〜18 個の小さな命。`gold` 半径 1〜2px・alpha 0.5〜0.9 + 各点 alpha 0.05 のグロー 1 層。周期 4〜7s の明滅（位相は点ごとにずらす）。星図がある場合は節点が alpha 0.35 に沈んで眠る。**操作前から作品世界が見え、文字より先に床が見える**（合否 7 の「埋もれない」は脇役化で満たす）
- 最初の指が触れた瞬間、触点に近い寝ている点 2〜3 個が alpha 0.9 に立ち上がる（文字より先に世界が応える）

## 6. 禁則と守ること

### taste-guide から参照したもの（合否チェックリスト対応）

1. 濁った茶色・オリーブ禁止（合否 1）→ 金は 2 値切替、低 alpha 多層の金を作らない（第 0 章）
2. 導入と操作後で質感が別物にならない（合否 2）→ 床・板の描画式は状態で変えない。動くのは alpha と照りの色温度のみ
3. 画面四辺での直線切断（合否 3）→ 開花・衝撃波は道に沿う／中心から。四辺に沿った直線の光は作らない（減光は光ではないので可）
4. 375px の存在感（合否 4）→ 第 5 章の独立スケール表
5. 操作結果が絵に残る（合否 5）→ 倒れた板は消灯しない（alpha 0.03 維持）、星図は蓄積
6. 白飛び（合否 6）→ finale でも最大輝度は `warmWhite` 未満。グロー積算 alpha 上限 0.12
7. 導入の文字が埋もれない（合否 7）→ 文字は脇役として下帯に置き、床の主役を文字より先に見せる
8. 重なり・はみ出し（合否 8）→ 描画不可マージン 24px、下部無視領域 48px
9. 安い描き方（合否 9）→ 太い原色リング禁止、グローは低 alpha 1〜2 層、エッジ反射は 1px の線
10. 統一感（合否 10）→ 色 4 系統 + alpha 演出のみ。どの状態も「暗い床に白と金の光」

### 本案固有の禁止

- パーティクルの噴水・紙吹雪・流れ星乱舞（星図の静謐さを壊す）
- 虹色・多色グラデーション
- 板の跳ね返り・弾みの物理（倒れは easeInQuad 1 種類のみ）
- 連鎖パルスの同時 3 枚以上
- グローの 3 層以上の重ね塗り
- 状態によって影の方向を変えること（光源は不変）
- 画面全体のフラッシュ・フェード演出

### 守ること（本書の適用範囲）

- `window.__art` 契約・音声解錠契約（`pointerup` / `touchend` / `click` / `keydown` 再開）・`pnpm verify` 契約は実装側の領分であり本書では触れない
- 本書は視覚仕様のみを定め、実装コード（コンポーネント分割・状態管理・音響エンジン）を指示しない
- 数値（alpha・px・ms・Hz）は実装の出発点であり、±20% の調整は許容する。ただし第 0 章の規律と第 6 章の禁則は調整対象外

## 7. 時間変化 ─ 主役が時間で移り変わる（第 2 強化ラウンド）

ユーザー評価「単調」への第 2 の答え。静止が許されるのは画面の構造（ガイド格子・遠景）だけで、**床と星図は全状態で生きている**。追加する動きはすべて既存の色 4 系統の alpha 変化のみで行い、新しい色・新しいレイヤーは作らない。

### 7.1 床の照りのドリフト（全状態・常時）

- `coolGlow` の斜めの帯が 24 秒周期で床を線形に横切る。帯は alpha 0.04 以下・帯幅 = `min(w, h) × 約 0.3` の斜めの軟らかい帯（硬いエッジは作らない。グラデーションの端を床に溶けるように置く）
- 第 1 章 L1 の放射照りの**上**、静的層（L0〜L3 焼き付け層 + 遠景）の**上**、板の**下**に描く
- 第 6 章の「光源は不変・影の方向を変えない」は維持する ─ ドリフトは照りの帯であり、影の方向は変えない
- L2 ガイド格子は**動かさない**（静けさの担保。動くのは照りの帯のみ）
- reduced-motion 環境ではドリフトを静止する（帯は位置固定のまま存在させる。点滅の強い動きを避けるアクセシビリティ対応）

### 7.2 星図の呼吸（intro と確定後の静置）

- 確定済みの節点が alpha 0.35 → 0.5 の範囲を周期 4〜7 秒のサインで脈動する。**節点ごとに位相をずらす**（星図全体がゆっくり波打つ。同期点滅は機械的に見えるので作らない）
- chain の間と、確定（自動確定の終わり）までの finale の間は凍結する（脈動の位相を保持したまま静止。連鎖中の動きの競合を避ける）
- 半径・位置・蕊は動かさない。動くのは節点の alpha のみ

### 7.3 finale 前の収縮（chain 終盤 15%）

- 連鎖進行度 t ≥ 0.85 の区間で、床の照りの半径比を 0.55 → 0.48 へ、照り alpha を 0.8 → 0.85 へ lerp する（照りが絞られて締まる。解放のための「息を吸う」動作）
- 開花の開始と同時に通常値へ戻す（解放）
- 第 3 章「明度・色温度の物語」の alpha 0.5 → 0.8 の補間と同じ層に掛ける。新しいレイヤーは作らない
