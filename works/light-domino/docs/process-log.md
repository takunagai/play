# 光のドミノ ─ 制作記録

## Phase 0: アイデア具体化

- お題「光のドミノの道を描いて、ひと押しで倒す」を変えず、操作を「なぞる → 端をタップ」、感情ゴールを「緊張と畏怖」に固定した
- 気持ちよさの核を、連鎖速度だけでなく「最後の直前に 160ms 音を引く → 最後の板・道全体の光・低音付き和音を同時に解放する」という同期で定義した
- 入力の巧拙を要求しないため、生の軌跡ではなく移動平均と弧長再サンプリングで板を配置する設計にした
- 暗い背景で金が濁るのを避けるため、`#FFC857` は不透明な細い芯として 1 回描き、周辺光を別レイヤーに分離した
- 画像素材は使わず、板、床、光跡、終演演出を 2D canvas で描く。画像発注は 0 枚
- `pnpm check` の初回は雛形にサムネイルが無く失敗した。企画の配色と構図を表す手続き生成 SVG を WebP へ変換して `public/thumbnail.webp`（1200×630）を置き、再実行で通過した。このサムネイルは画像生成モデルによる素材ではないため `generatedImages` は空のまま
