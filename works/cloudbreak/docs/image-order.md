# Cloudbreak ─ 画像発注書

## 発注枚数

生成画像なし（0 枚）。

## 判断理由

主役は、長押し時間に連続して反応する高度、層ごとに異なるパララックス、雲が押し分けられる動き、最終層の密度、突破時に画面下へ退く雲、晴天後に見下ろす雲海である。固定画像では任意の高度と速度に合わせて雲の密度、裂け目、奥行きを連続変化させにくく、同じ雲の反復にも見えやすい。seed 付きの 2D canvas 描画なら、楕円比、塊の数、切れ目、移動方向、遠近速度を層別に生成し、375px〜1280px で解像度非依存の構図を保てる。

したがって Tier 1 は手続き描画だけで成立させ、`work.json` の `generatedImages` は `[]` のままとする。画像モデルへの prompt、生成寸法、黒背景、`--black-to-alpha` の指定はいずれも対象なし。VPS の素材置き場への納品もない。

`public/thumbnail.webp` は生成画像ではない。構想時点では、設計パレットと雲海構図を用いた手書き SVG を一時入力として、リポジトリの画像準備スクリプトで 1200×630 の WebP に変換する。実装後は `pnpm verify` の決定的な突破場面から作り直せる。生成モデルを使っていないため `generatedImages` へは記録しない。

## 将来の仕様変更時の条件

現設計では発注しない。人間が固定素材を求める仕様へ変更した場合も 10 枚上限を守り、各画像に用途、寸法、正確な prompt、採用基準を追記する。発光素材に透過が必要なら、生成モデルへ透過を頼まず黒背景で生成し、`--black-to-alpha` で変換する。本カードの範囲には含めない。
