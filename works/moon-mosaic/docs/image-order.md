# Moon Mosaic ─ 画像発注書

## 発注枚数

生成画像なし（0 枚）。

## 判断理由

主役は、指の速度に応じて位置と向きが変わる銀の欠片、欠片が通った弧、中央で閉じる月、重なる水面の波紋である。すべて操作と状態機械へ連続的に反応し、解像度や画面比率にも追従する必要がある。固定画像を使うと、欠片の継ぎ目、月の閉じ方、星図の航跡が入力と一致しなくなり、「自分が引き寄せて作った月」という因果を弱める。

銀片は seeded な凸多角形、水面は 3 色パレットの alpha 合成、波紋と月輪は 2D canvas の細線、星図は入力経路の弧長再サンプリングで描ける。これにより画像デコードを避け、375px〜1280px で同じ密度と輪郭品質を保てる。したがって Tier 1 では外部画像を発注しない。

`work.json` の `generatedImages` は `[]` のままとする。保存ファイル名および `scripts/prepare-image.mjs` の実行対象はない。

将来の仕様変更で発光テクスチャが必要になった場合も、透明 PNG を生成モデルへ依頼しない。黒背景で発光素材を生成し、`public/images/<name>.webp` へ `node scripts/prepare-image.mjs <in.png> <out.webp> --black-to-alpha --max <px>` で透過 WebP 化する。ただし現行の 3 色パレットと手続き描画で成立するため、本発注には含めない。
