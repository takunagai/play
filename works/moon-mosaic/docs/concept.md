# Moon Mosaic ─ コンセプトシート

- 作品名: Moon Mosaic（候補: 1. Moon Mosaic / 2. Silver Tide / 3. Lunar Cartography。slug と作品名は発注時の決定に従い 1 を選定）
- 感情ゴール: 驚き・発見
- コア操作: 引き寄せと反発 ─ 銀の欠片へ指を近づけると一度逃げ、ゆっくり運ぶと指の後ろを弧で追い、中央の月へ収まる
- 参照イメージ: 墨を流した夜の水面、割れた鏡の銀片、月へ結ばれる航路、細い星図
- ビジュアル: モノクロ＋単色差し。背景の墨青 `#08111F`、水面の青灰 `#1D3A52`、欠片と月の銀白 `#EAF6FF` の 3 色だけを使う
- 音: アンビエント・ドローン、D ドリアン。水滴と短いグラスハープを 8 分拍で少しずつ上げ、完成時だけ長い胴鳴りを加える
- プラットフォーム: ウェブ（2D canvas + Web Audio） / 入力: マウス・タッチ / 公開: play.nagai-shouten.com / 規模: Tier 1 の小品、375px〜1280px、60fps 目標

## お題の翻案

画面は、最初から完成形を見せるパズルではなく、指の速度を読む水面である。銀の欠片はカーソルへ即座に吸着しない。近づいた気配から小さく逃げ、指が落ち着いたときだけ遅れて航跡へ入り、左右どちらかの大きな弧を描いて中央へついてくる。速く追えば反発距離が伸び、ゆっくり先導すれば従うため、ユーザーは説明を読まずに「追うのでなく待って運ぶ」手つきを発見する。

中央へ収まった欠片は消えず、銀白の薄片として月の円を少しずつ埋める。未回収の欠片も水面に残り続けるので、完成前に画面が空にならない。欠片が通った経路はごく細い線と節点として残り、完成後に初めて、それらが月へ向かう星図だったと分かる。

抽選されたコア操作「育てる・枯らす」は、完成した形を育成する操作よりも、指との距離と速度で逃避／追従が切り替わるお題の因果を弱めるため採用しない。正本のお題を優先し、語彙は「引き寄せと反発」とする。

## 体験の流れ（30 秒シナリオ）

0〜3 秒、墨青の水面に銀の欠片が遠く離れて漂い、中央には月が入る空の円だけが水面の濃淡でかすかに見える。3〜8 秒、ユーザーが欠片へ指を近づけると、欠片は短い水滴音とともに小さく逃げるが、指をゆっくり中央へ運び直すと、指の後ろから弧を描いてついてくる。8〜22 秒、欠片が中央へ収まるたびに波紋が重なり、8 分拍のグラス音が D ドリアンを少しずつ上り、通った弧が細い星図として蓄積する。22〜27 秒、最後の欠片が月へ触れた瞬間、波紋も音も 0.15 秒だけ完全に止まり、止まった水面が期待を受け止める。続く一瞬に白い月、高いガラス音、輪郭を一周する短いクリック、低い胴鳴りが同時に現れ、月の縁だけを光の輪が走る。27〜30 秒、完成した月は水面の揺れに合わせて静かに歪み、残った航跡と重なって一枚の夜の地図になる。その余韻の中、次に導く銀の欠片群が別の場所へ静かに現れる。

## 気持ちよさの核

最重要の報酬は、最後の欠片そのものではなく「無音の間 → 月の輪」の同期である。最後の欠片が収まった直後の 150ms は、新しい波紋の生成、既存波紋の進行、欠片の漂い、ドローン、残響をすべて凍結または急速に絞る。150ms 後の同じ時刻に、次の 3 つを開始する。

1. 高いグラスハープ音を長めに伸ばす
2. 月の輪郭を一周する短いクリック列を走らせる
3. 小さな太鼓の低い胴鳴りを立ち上げる

視覚も同時に、中央の銀白面を 0 から白く塗るフラッシュではなく、すでに集まった欠片の継ぎ目が閉じ、細い輪が一周する変化として開く。画面全体の明度は上げず、水面の青を必ず残す。

## 3 色パレットの使い方

| 色 | 役割 | 規律 |
|---|---|---|
| 墨青 `#08111F` | 最背面、周辺減光、欠片の影 | 毎フレーム不透明に塗り、画面の静けさと暗部を維持する |
| 青灰 `#1D3A52` | 水面の面、波紋、中央の空の円 | 同色の alpha と明度差だけで層を作る。白を混ぜた別色は増やさない |
| 銀白 `#EAF6FF` | 欠片、月、完成後の輪、星図の芯 | 面積を絞る。完成時も全画面へ広げず、月の縁と航跡だけを最も明るくする |

波紋は青灰、航跡は低い alpha の銀白、月の面は銀白を用いる。加算合成は月の輪と航跡のごく薄い外側に限定し、同一点で何層も重ねない。白飛びで水面の青が消える演出、太い原色リング、低 alpha の橙〜黄緑は作らない。導入時と完成時で欠片の材質を変えず、銀白の薄片という同じ光学モデルを保つ。

## 操作と失敗しないための約束

- 指へ即座に吸い付けず、短い逃避のあとに速度が落ち着いたときだけ追従へ移る
- 速く動かすほど反発距離は増えるが、画面外へ逃げない。端では水面側へ滑らかに返す
- 中央へ収める判定は見た目より広くし、正確なドラッグを要求しない
- 追従を外しても欠片は消えず、その場で漂いへ戻る。失敗音、得点、警告文は置かない
- マウスとタッチを同じ Pointer Events で扱い、1 本の主ポインタだけを受ける
