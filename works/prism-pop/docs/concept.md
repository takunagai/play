# Prism Pop ─ コンセプトシート

- 作品名: Prism Pop（候補: Awanari（泡鳴り） / Fizz Chime / Prism Pop から選定）
- 感情ゴール: 快感・連打
- コア操作: 弾く・割る ─ 漂う泡をタップで割ると、ベルの音が鳴り、連打するほど和音が積み上がる
- 参照イメージ: 炭酸・シャボン玉の泡（お任せ→提案）。光を受けて虹色に揺れる泡膜、割れた瞬間に飛ぶしぶき
- ビジュアル: 有機的グラデーション。泡は虹色の薄膜（干渉色）、背景はゆっくり流れるグラデーション。パレット基調 ライム #C6FF00 × バイオレット #7C4DFF（背景は両者の暗い中間色、泡の縁と破裂光に原色を使う）
- 音: アコースティック風（ベル・マリンバ）、リディアン
  - 泡の大きさで音域が決まる（大きい泡 = 低いマリンバ、小さい泡 = 高いベル）
  - 連打のコンボ中は鳴らす音をリディアンの構成音の一部（主音・3 度・5 度・#4）に絞り、和音が濁らないようにする（お任せ→提案）
- プラットフォーム: ウェブ（p5.js + Web Audio。Strudel は使わない） / 入力: マウス・タッチ（マルチタッチで同時割り） / 公開: ローカルで楽しむ / 規模: 適応型 ─ 標準（2D 描画・スマホ対応・60fps 目標）で起動し、端末性能に余裕があれば自動でリッチ（WebGL シェーダで泡膜の干渉色・屈折を描く）へ昇格。重くなったら標準へ自動降格
- 体験の流れ（30 秒シナリオ）:
  画面には虹色の膜をまとった泡がいくつも、グラデーションの中をゆっくり昇っている。なんとなく 1 つタップすると、泡は光のしぶきを散らして割れ、「ポン」と澄んだベルが鳴る。続けて近くの泡を割ると 2 つ目の音が 1 つ目に重なり、和音になる。テンポよく割り続けるとコンボが伸び、音は上の音域へ駆け上がり、背景の色がライムからバイオレットへ明るく揺れる。手を止めると残響だけがしばらく漂い、また新しい泡が湧いてくる。
