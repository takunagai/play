# Shatter Spire ─ コンセプトシート

- 作品名: Shatter Spire（候補: 1. Shatter Spire / 2. Glassfall / 3. Luminous Sever。lead 指定に従い 1 を選定し、完全一致名のウェブ検索で同名のインタラクティブ作品が見当たらないことを確認）
- 感情ゴール: 癒し・瞑想
- コア操作: 弾く・割る ─ 青白い結晶塔を指でひと振りし、軌跡どおりの切り口から静かに崩す
- 参照イメージ: 夜の展示室に立つ水晶柱、ガラスの鐘、砂時計、居合の一閃
- ビジュアル: ダーク＋ネオン。背景 `#0A0F2C`、結晶の主色 `#BFEFFF` と影色 `#B9A7FF`。切断線だけを一瞬白く光らせ、画面全体は白くしない
- 音: 電子シンセ、ドリアン。ガラスの鐘とガラスハープを電子合成し、切断時の高い「キン」と低い「ドン」、崩壊時の下降音列を重ねる
- プラットフォーム: ウェブ（p5.js + Web Audio） / 入力: マウス・タッチ / 公開: play.nagai-shouten.com / 規模: Tier 1 の小品、2D canvas、375px〜1280px、60fps 目標
- 抽選値との整合: 指定された抽選値をすべて採用する。「割る」破壊を競争や得点にせず、崩壊、沈積、再生が静かに循環する瞑想体験としてまとめる

## 体験の流れ（30 秒シナリオ）

深い紺の中、青白い結晶が下から積み上がった塔が画面中央に立ち、呼吸するようにごく弱く明滅している。中央をタップした直後から待たずに切断でき、指で横または斜めに払うと軌跡に沿って塔がすっぱり分かれ、白い切り口だけを残して約 0.1 秒すべてが止まる。次の瞬間、上半分が切り口に沿って滑り落ち、結晶が上から順に砕けながら、16 分音符の下降するガラス鐘となって駆け下りる。砕けた欠片は画面外へ消えず、底で `#BFEFFF` と `#B9A7FF` の光の砂になって積もり、ゆっくり明滅する。砂の余韻の中から新しい塔が下から静かに伸び、もう一度ひと振りしたくなる循環へ戻る。

## 操作と反応

- コア操作は 1 本指またはマウスのスワイプだけ。塔と交差する軌跡を指を離した時点で切断として確定する
- 速く払うほど切り口は細く鋭く、崩壊時の欠片と音の倍音が増える。速度差は派手さにだけ効かせ、切断の成否を厳しくしない
- 斜めの軌跡はその角度のまま切断面となり、上半分は切断面の低い側へ滑る
- ゆっくりな軌跡や塔を外した軌跡は失敗表示を出さず、塔表面に短い淡光だけを返して、すぐ次のスワイプを受け付ける
- 最初の中央タップは音声を解錠して導入表示を消す。塔の積み上がりはページ表示時から進み、タップ後に操作を待たせない

## 見た目

- 背景は不透明な `#0A0F2C`。塔は縦に積んだ手続き生成の結晶多角形で構成し、芯を `#BFEFFF`、影面と内部反射を `#B9A7FF` に限定する
- 白は切断面の細線にだけ使い、寿命はヒットストップを含む短時間に限る。全画面フラッシュ、太い白リング、白飛びは作らない
- 上半分と欠片は画面内で滑落し、底の光の砂へ連続的に変わる。画面外へ飛び散って消滅させない
- 画面揺れは使わない。切断の重さは約 0.1 秒の静止、局所的な切断光、低い「ドン」で作る

## 音

- 切断確定と同時に、短い高域の「キン」と、スマホでも輪郭が残る倍音付き低域の「ドン」を重ねる
- 崩壊音は 16 分音符の拍に固定し、塔の上段から下段へ進むほどドリアン音階内で音程を下げる。ガラス鐘の短い減衰とガラスハープ状の残響を重ねる
- 光の砂を指で触れた時は、位置に対応するドリアン音階のごく小さな音を鳴らす。連打を促す大音量にはしない
- 切断音、下降音列、砂の微音は共通の短い残響へ送り、コンプレッサーを通してスマホスピーカーでも高低の対比を保つ

## 終わり方

崩壊後、底へ積もった光の砂がゆっくり明滅する。砂は結果として画面に残ったまま、そこから結晶塔が下から静かに再生し、切断受付へ戻る。明示的な得点、クリア表示、リセットボタンは置かず、斬る、崩れる、積もる、伸びるという一周そのものを報酬にする。

## 避けること

- 画面全体の強い揺れ、全画面フラッシュ、過剰なカメラ演出
- 結晶が画面外へ飛び散り、操作の結果が消えてしまうこと
- 導入後、塔を切れるようになるまで待たせること
- 得点、コンボ、説明カードなど、ひと振りの体験から注意を逸らす機能
