# 星を結ぶ夜 ─ 画像発注書

**0枚、生成不要。**

- 生成画像の発注 0 枚、生成 0 枚。画像モデル・外部サービスへの送信・課金を行わない。
- 星の芯・暈・吸引・細い線・消退は Canvas2D で手続き的に描く。固定画像で入力に追従する星群の形を代替しない。
- オルゴールは Web Audio の自前合成。音声ファイルの発注もない。
- ファイル名・寸法・透過・プロンプト・モデル・素材納品先は該当なし。VPS の素材置き場にも今回の納品物はない。
- `work.json.generatedImages` は `[]` を維持する。

## サムネイルとの区別

構想段階の `public/thumbnail.webp` は初期化時の `pnpm check` に必要な構想用の仮画像。設計パレットと星・線を図示した手製の模式図であり、画像モデルの生成物でも実装のスクリーンショットでもない。完成画面の証拠として使わない。

仕上げ担当は実装後の `pnpm verify star-thread` のスクリーンショットから `scripts/prepare-image.mjs --cover 1200x630` で同ファイルを置換する。これも画像生成には数えない。最終絵に星と線の結果が残っていることを確認する。

画像を必要とする仕様変更は、本書と設計正本を先に更新して lead の判断を受ける。今回の 0 枚を黙って増やさない。
