# 星を結ぶ夜 ─ コンセプトシート

本カードは構想と雛形初期化のみ。以下は完成形の設計であり、現在の雛形のベル・波紋を作品の完成とは扱わない。

- 作品名候補: 1. 星を結ぶ夜 / 2. 星をあつめる指 / 3. 夜空の糸。人間の固定指定に従い 1 を採用する。
- 名前の確認: 2026-11-06 に完全一致検索 `"星を結ぶ夜"` を実行。検索結果では同名の作品・サービスを確認できなかった。「星を結ぶ前のある夜」「星結ぶとき」等の類似名はある。網羅性・商標の保証ではない。
- 感情ゴール: 驚き・発見。指に寄った小さな光が、自分だけの星座と旋律になる発見。
- コア操作: 引き寄せと反発 ─ 長押しで星を引き寄せ、離すと星座が順に結ばれて鳴る。語彙の「反発」は星同士の重なりを避ける弱い分離だけに使い、星が指から逃げる挙動にはしない。
- 参照イメージ: 濃紺の夜空、指に集まる温かい光点、細い光の糸、小さなオルゴール。既存の星座名や正解の形は使わない。
- ビジュアル: ダーク＋ネオン。背景 `#0B1026`、星と線の色 `#FFD27A`、星の芯だけ `#FFF3D6`。暖色を大きな半透明の背景面にしない。星の芯と小さな暈の対比で透明感を作る。
- 音: アコースティック風、メジャーペンタ。A を主音とする明るい五音のオルゴール。星一つにつき一音、線の到達と光の増光を同じ時刻にする。無操作・吸引中は新規発音なし、解放後の余韻だけを許す。
- プラットフォーム: ウェブ / 入力: マウス・タッチ（同時 2 指まで）/ 公開: play.nagai-shouten.com / 規模: Tier 1 の小品。
- 生成画像: 0 枚。Canvas2D の手続き描画と Web Audio の自前合成音のみ。外部アセット・CDN・API・マイク・カメラ・保存機能を使わない。
- お題優先: 抽選の CRT・ノイズ・マイナーは、お題の静かな金の星と明るいオルゴールに反するため不採用。

## 体験の流れ（30 秒シナリオ）

0〜3 秒、同じ質感の星が中央でゆっくり寄り、中央タップで説明を読むことなく夜空へ入る。3〜6 秒、約 0.3 秒押して短くなぞるだけで 4 個の星が指へ寄り、離すと光の糸が一つずつ結ばれ、4 音が鳴って小さな星座が残る。6〜13 秒、今度は約 2.7 秒保持すると 12 個まで増え、広い星座と長い旋律になるため「押す長さを変えると自分の絵と音が変わる」と気づく。13〜21 秒、2 指を離して置くと互いに奪い合わない二つの星群が集まり、片方ずつ離すと二つの星座が別々に結ばれて重なる。21〜30 秒、線が数秒残って静かに薄れ、星が空へ戻る間に別の場所をもう一度触れたくなる。

## 手応えの約束

1. 押下から 80ms 以内に近傍の星が動き、明るくなる。長押し成立まで待たせず、速い指から逃がさない。
2. 0.3 秒操作でも 4 星・4 音・3 本の線を返す。短押しを失敗にせず、満充填を成功条件にしない。
3. 0/0.3/1.2/2.7 秒で 3/4/7/12 星。星数だけでなく広がりも増え、2.7 秒で上限。以後は穏やかな呼吸で保持可能なことを伝え、自動暴発しない。
4. 解放から最初の増光・発音まで、音声が稼働済みなら 120ms 以内。全体を爆発・白フラッシュ・太い輪にしない。
5. 最終音後は 2 秒保持、続く 2 秒で消退、0.6 秒で空へ戻す。結果を見せたまま次の操作を受け付ける。
6. 2 指は所有も時刻も独立。近づいても一つに融合させず、片方の解放で他方を解放しない。

数値の式・例外・検証許容差は [architecture.md](architecture.md) を正本とする。

## 不採用作から引き継ぐ基準

- moon-mosaic（PR #5）: 光のない単色形、指から逃げる追従、10 回操作しても報酬に届かない問題が記録されている。本作では即時の吸引、光点の芯と暈、最初の一回から残る星座で対処する。
- Cloudbreak（PR #8）: 人間の不採用理由は「インタラクション性や楽しさも心地よさも感じないし、ビジュアル表現も特筆すべき点がないため」。技術ゲートが通った事実はこの評価を覆さない。本作は押す長さ・移動・2 指で星の配置と音の並びが変わること、静かな線の到達と一音の一致を審美・試遊の対象にする。
- 自動 pass は起動・音・性能の最低条件であって、楽しさの合格ではない。審美担当は 375px/1280px の導入・吸引・解放・余韻を見比べ、試遊で短押しと長押しをもう一度試したいかを別に記録する。
